# Security policy

Do not disclose a vulnerability or suspected secret in a public issue. Use the contact published at `https://mocre.es/.well-known/security.txt` and provide a minimal, redacted reproduction.

MOCRE is research software and is not an earthquake early-warning system. Security reports should distinguish software vulnerabilities from scientific-model limitations; the latter belong in ordinary research discussion unless they expose data or system access.

Before a public push, run `scripts/verify-public-release.sh` with a current Gitleaks binary.
